# FlorenSwitcher

Данный скрипт меняет погоду и время в клиенте SAMP на любом сервере.

Установка

1. Поиестите luac скрипт в папку "корень GTA SA/moonloader"

2. Запустить игру и ввести команду /time, /weather (их можно изменить в конфигурационном файле)

3. Готово!
